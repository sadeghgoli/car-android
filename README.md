# ارجاع خودرو ۱۳۷

نرم‌افزار تبلت خودروهای اجرایی شهرداری سبزوار برای دریافت، نمایش و اجرای درخواست‌های ارجاع‌شده از سامانه ۱۳۷.

## تکنولوژی

- Expo 57 / React Native
- MapLibre (نقشه محلی سبزوار)
- React Navigation
- SSO تستی + داده mock

## اجرا

```bash
npm install
npx expo start
```

نقشه Native روی دستگاه/تبلت به Dev Client نیاز دارد:

```bash
npx expo run:android
```

## حساب‌های آزمایشی

- ورود به‌عنوان اپراتور: علی محمدی (بدون تنظیمات)
- ورود به‌عنوان مدیر: رضا کریمی (تنظیمات تبلت و خودرو)

حدود ۹ ثانیه پس از ورود، یک درخواست بحرانی جدید به‌صورت لحظه‌ای به فهرست اضافه می‌شود.
اگر GPS در دسترس نباشد، حرکت و هشدار سرعت شبیه‌سازی می‌شود.
